## Used

### Python

#### Input and output

- `input()`
- `print()`

#### Numeric Types — `int`, `float`, `complex`

##### Numbers operations

- `42 + 42`
- `42 - 42`
- `42 * 42`
- `42 // 42`
- `42 % 42`
- `42 ** 42`
- `num += 42`
- `num -= 42`
- `num *= 42`
- `num //= 42`

###### Numbers comparison

- `42 == 42`
- `42 != 42`
- `42 > 42`, `42 < 42`
- `42 >= 42`, `42 <= 42`

##### Numbers functions

- `max(42, 4.2)`

##### `float`

- `float('4.2')`

##### `int`

- `int()`
  - `int('42')`

#### Sequence Types — `list`, `tuple`, `range`

##### `range`

Doc: `class range(stop, /)`, `class range(start, stop, step=1, /)`.

- `range()`

##### `tuple`

Doc: `class tuple(iterable=(), /)`.

###### Tuples operations

- `variable_1, variable_2 = expression_1, expression_2`

- `string_value[index]`, `string_value[-index]`
- `string_value[i:j]`, `string_value[i:j:k]`

##### Strings operations

- `string_variable += string_value`

- `string_value_1 in string_value_2`

- `f''`

###### Strings comparison

- `string_value_1 == string_value_2`, `string_value_1 != string_value_2`

##### Strings functions

- `chr(42)`
- `ord('ё')`

- `len(string_value)`
