# Yandex. 2.2. Technologies

## Used

### Python

#### Input and output

- `input()`
- `print()`

#### Numeric Types — `int`, `float`, `complex`

##### Numbers operations

- `42 + 42`
- `42 - 42`
- `42 * 42`
- `42 // 42`
- `42 % 42`
- `42 ** 42`
- `num += 42`
- `num -= 42`
- `num *= 42`

###### Numbers comparison

- `42 == 42`
- `42 != 42`
- `42 > 42`, `42 < 42`
- `42 >= 42`, `42 <= 42`
- `42 == 42 == 42`
- `42 >= 42 >= 42`, `42 >= 42 > 42`, etc.
- `42 <= 42 <= 42`, `42 <= 42 < 42`, etc.

##### Numbers functions

- `max(42, 4.2)`
- `min(42, 4.2)`

##### `float`

- `float('4.2')`

##### `int`

- `int()`
  - `int('42')`

#### Text Sequence Type — `str`

- `'str' * 42`

- `'str' in 'str'`

- `f''`
  - `f'{string_value}'`
  - `f'{string_value:^{length}}'`
  - `f'{string_value:>{length}}'`

###### Strings comparison

- `'str' == 'str'`, `'str' != 'str'`
- `'str' > 'str'`, `'str' < 'str'`

##### Strings functions

- `len('str')`
- `min('str', 'str')`

#### Conditions

- `if condition:`, `elif condition:`, `else:`
- `condition_1 and condition_2`
- `condition_1 or condition_2`
